# Палитра кода
Статичный сайт: главная со списком языков, поиск, категории, прогресс, светлая и тёмная тема.

Все файлы кладутся в корень репозитория, имена строго в нижнем регистре:
index.html, style.css, app.js, data.js, data2.js

GitHub Pages: Settings → Pages → Branch: main, папка / (root).
Добавить язык: блок в data2.js + строка в META в app.js (категория, сложность, значок).
